# Isaac Sim 独立数据采集移植

目标：参考 run003 已验收成功轨迹的质量，复用当前资产、任务几何、IK、CuRobo 和格式，在没有导入 Isaac Lab 的运行进程中重新执行至少六个差异较大的抓放方向。

参考源：`data/curobo_pick_place_graph_run003_success_20261004/archive_manifest.json`。只使用推荐且通过原验收的轨迹；2→4 的 unvalidated 文件不计入候选。

执行范围沿用 run003：自由空间 CuRobo 规划及状态写入，接触段真实 PhysX/IK 执行，携物转运使用实测抓取变换，另生成三路状态回放。托盘接触保持 run003 诊断策略，不能扩展宣称全程纯物理转运。

首个可验证版本是单路线原生场景/接触执行/产物构建/三相机回放。最终交付仍须六组完整执行与同格式数据，首路线通过不代表目标完成。

## 复用与接口

- 复用 `configs` 的 USD、场景、驱动、TCP 坐标和相机配置，保留 USD 内 HandCamera。
- 原 IK 核心和纯数学模块本地化，保留控制算法；`native/control_provenance.json` 记录来源和移植边界。
- 使用 Isaac Sim Core 的 World、Articulation、RigidPrim、Camera，适配既有采集器的实测状态接口。
- 复用原 CuRobo 规划、碰撞门槛、NPZ 构建与验证、JSON trace 和稀疏三相机 PNG/frames.json。
- 新输出写入独立目录，参考数据不覆盖。

## 已处理的运行差异

- 直接添加 USD reference，避免 Core 的 MetricsAssembler 对既有夹爪关节限位重复执行单位缩放。
- 腕部相机从渲染器 `camera_params` 读取完成帧的外参，不为移动父节点下的相机创建 Fabric 世界变换覆盖；每次采样均与实测挂载连杆的位置和朝向核对。
- 相机启动预热同时检查 RGB 内容，等待几何与材质加载完成，拒收有效缓冲中仍存在的灰色占位图。
- 三路实际渲染引用必须相同，且每次导出持续更新；固定相机位姿和三路内参直接与参考数据核对。
- 参考归档混有 128×128 和 640×480 图像。新采集统一使用 640×480；校验读取参考 PNG 的实际尺寸，按保留水平 aperture 和方形像素的规则缩放焦距/主点后比较内参，避免把分辨率差异误判成标定改变。
- `--resume` 可以复用已经通过的原生物理执行和构建产物，只重新生成失败/中断的回放；失败图像、报告和日志另存，避免覆盖证据。

## 最终验收

1. 至少六个不同方向，优先覆盖所有五个状态及 state4 出入；按归一化时间的关节轨迹差异做最远点选择，记录选择依据。
2. 每个新执行与回放进程记录 backend=isaacsim 和空的 isaaclab_modules_loaded，零模块导入是硬门槛。
3. 现场网格拓扑与基线一致，顶点误差≤0.2微米。哈希不同必须记录现场和冻结规划哈希，并逐网格验证后才复用冻结规划几何；基座、初始关节、相机模型和分辨率保持当前配置。
4. 每组接触段实际物理步进并从 PhysX 读取 q/dq/TCP/物体姿态；接近、夹爪、抬升、放置门槛沿用原逻辑，放置后物体误差≤20 mm。
5. 新轨迹经过原 artifact builder 与 verify_hybrid_artifact，位置/速度/加速度、自由空间碰撞、事件与段顺序通过，不降低门槛。
6. 每组产生原格式 trajectory.npz、scene_snapshot.json、plan_report.json、接触 report/trace、replay_report.json 与两套 640×480 三相机 PNG/frames.json；全部图像可解码、索引/时间/内外参与 trace 一致。
7. 独立总审计逐项读取真实输出，记录来源、SHA256、质量和数量；参考归档中已有文件的 SHA256 保持不变。

实际出现的阻塞问题在移植中处理，失败候选保留。只有满足全部条件才判为完成。

## 已完成的验收

2026-10-09，4→1、3→0、0→3、4→3、4→2、3→4 六组全部通过批量采集与独立总审计。共 3,862 个轨迹样本和 1,920 张 640×480 RGB 图像，最大放置位置误差 11.33 mm，新轨迹两两最小关节 RMS 差异 0.681899 rad。十二份有效运行报告的 Isaac Lab 加载列表均为空，原归档 7,736 个文件哈希保持不变，59 项回归测试通过。

完整结果见 [验收报告](../data/isaacsim_run003_20261009_r2/RESULTS.md)，机器可读证据见 [独立审计](../data/isaacsim_run003_20261009_r2/independent_audit.json)。
