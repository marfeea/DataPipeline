# DataPipe 项目边界

## 本项目拥有

- `DataPipe/`：episode/action/observation 契约、schema v3、HDF5
  读写与校验、轨迹与 pick-place 阶段机、相机/夹爪 Isaac 适配、采集、重播、
  R2Dreamer batch 和 Mamba sequence buffer。
- `tests/test_datapipe_*.py`：不依赖 Isaac 的数据契约回归，以及使用本地配置的
  相机配置检查。
- `data/`：运行时数据输出目录；默认被 Git 忽略，不属于源码。

## 外部运行时依赖

全部 14 个配置模块已于 2026-09-05 从相邻 CurriculumRL 仓库复制到 `configs`。
本项目直接读取本地配置；外部运行时内部仍读取自己的配置，修改快照时需保持兼容。

本地配置与外部接口如下：

- `configs.assets`：机器人 prim、关节和场景实体名称；
- `configs.task`：目标 states、TCP/Flange 标定、抓取距离和方向轴；
- `configs.render`、`vision_diagnostics`：viewport 与三路 CameraSensor 标定；
- `configs.training`：物理仿真步长；
- `CurriculumRL.logic.aubo_ik`、`tcp_kinematics`：FK/IK、Flange-down heading 和坐标变换；
- `CurriculumRL.tasks.tcp_docking`：正式 Gym 环境、动态场景、IK action term、奖励与终止状态。

配置模块完整保留常量、数据类和辅助函数，其余运行时代码与 USD 资产不复制。
采集和回放自动发现相邻 `CurriculumRL` 仓库，也可通过
`DATAPIPE_CURRICULUMRL_ROOT` 指定仓库或 editable 安装运行时。

## 明确不属于本项目

- 正式 RL 环境的动作空间、奖励、课程、成功与安全终止定义；
- AUBO 数值 IK 算法和 Jacobian 实现（关节与执行器配置已有本地快照）；
- 机器人、工作站、采样瓶和实验室 USD 资产；
- SB3/RSL-RL/RL-Games/SKRL 的正式训练入口与 checkpoint；
- 生成的 HDF5/JSONL 数据、渲染图像和 Kit 缓存。

## 依赖方向

依赖必须保持单向：`DataPipe -> CurriculumRL`。`CurriculumRL` 产品代码不得反向导入
`DataPipe`。需要改变机器人几何、控制器、奖励或环境终止时，应在 CurriculumRL 修改并
通过其公共接口发布；需要改变数据 schema、采集阶段、writer、validator 或 replay 时，
应在 DataPipe 修改。

## 迁移兼容期

迁移完成并验证前，原仓库中的 `CurriculumRL/datapipe` 保留为工作树快照，避免删除尚未
提交的改动。目标仓库 `DataPipeline/DataPipe` 是后续 DataPipe 开发的权威位置；确认调用方
全部切换后，再单独删除原副本或改成兼容入口，不能长期双向修改。
