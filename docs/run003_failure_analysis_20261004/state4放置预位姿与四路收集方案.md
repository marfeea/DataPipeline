# state4 放置预位姿与四路数据收集

本轮目标是找到可用的 state4 放置预位姿，并完成 0→4、1→4、2→4、3→4 四路的完整轨迹、现场三相机图片、GUI 回放和独立验收。0→4 作为首个可验证 MVP；其成功不代替其余三路的完成。

2026-10-05 检查当前进程，没有仍在运行的 Isaac 收集进程。前一阶段 0→4 的 180/240 mm 水平外移都出现插入时倾斜与 Z 跟踪误差。新离线重建读取原始实际抬升 TCP 和物体位姿，保持原证据不变，得到标称最终 TCP 对应的物体最低点世界 Z≈1.08421 m，期望放置最低点≈1.09150 m，低约 7.29 mm；上方遮挡底面≈1.144 m，预计顶部≈1.12888 m，仍有 15.12 mm。这里是携物刚性变换与网格包围盒推断，不是已识别具体 PhysX 接触对的证明。

首轮候选把外侧下降预位姿与水平插入预位姿都抬高 8 mm。对应预测最低点≈1.09221 m、顶部≈1.13688 m，先验证是否能避开下边缘且保留上方净空。水平到位后仍接近原最终 TCP，再按既有逻辑松爪。统一转运净空 300 mm，先采用已测试的 240 mm 外移；抓取终点、物体最终目标、场景障碍、碰撞模型和门槛不变。若真实执行说明需要进一步调整预位姿或姿态，再根据实测数据选择下一候选。

实施顺序：将新预位姿参数贯通任务快照、任务哈希、生产状态机、路线收集器和接触执行；保留默认 0 mm 时所有历史任务几何与哈希。用新实验目录冻结配置和实现，不覆盖旧失败记录。先做 0→4 的有头执行；再分别验证 1→4、3→4；2→4 的源端预抓取自碰撞需要单独核对真实几何并解决，然后完成该路线。

每路验收：所有目标 IK、自由空间世界与自身碰撞、轨迹关节位置/速度/加速度、接触到位和夹爪门槛按原规则通过；最终实测物体位置误差≤20 mm；GUI 回放通过；现场和回放三相机 640×480 图片可解码且正确绑定实际 trace/轨迹与任务哈希；独立路线审计通过。沿用 run003 混合规划/物理接触/状态回放范围，接触托盘碰撞继续作为诊断项。任何失败候选保留，不能因图片保存成功计为动作成功。

完成条件：四路全部验收通过，将成功轨迹和可视化加入统一成功目录，并记录经验证的参数与证据；原 13 个成功方向的归档、基线场景和碰撞模型保留。未通过的路线继续处理具体阻塞，不以单路成功缩小目标。

首个离线证据：[实测放置重建](state4_measured_placement_20261005.json)。
