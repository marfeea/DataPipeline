# 五状态稳定放置接入

本轮 MVP：将 2026-10-13 搜索并独立验证的五个松爪位置写入 `configs/task.py`，由主采集入口 `scripts/collect_isaacsim.py` 默认使用。原坐标保留在每个状态旁的注释中。

| 用户位置 / 脚本索引 | 松爪时物体根位置 E（m） | 动作 |
|---|---|---|
| 1 / 0 | (1.539, 0.203, 0.9365) | 高处 XY 对齐，补偿跟踪误差，下降 |
| 2 / 1 | (0.91167, 0.1753, 0.97089) | 高处 XY 对齐，下降 |
| 3 / 2 | (0.91167, 0.03036, 0.96976) | 高处 XY 对齐，下降 |
| 4 / 3 | (0.91435, -0.18557, 0.99391) | 高处 XY 对齐，下降 |
| 5 / 4 | (0.90264, -0.50461, 1.0945) | 层外下降，240 mm 水平进入，补偿跟踪误差，下降 5 mm |

`place_object_position_e` 表示松爪前物体的根位置。原 `position_e` 仍定义初始物体位置和最终成功目标，`grasp_tcp_position_e` 仍用于抓取。这样不会把物体坐标误当成 TCP，也不会通过改变成功目标放宽门限。

采集器保留参考轨迹的抓取和运输，在进入放置段时读取当前真实 TCP 和物体位姿，计算本次 TCP–物体关系，并换算松爪 TCP 的完整位置和四元数。随后只发送关节/夹爪目标，由 PhysX 积分产生观测；不写机器人或物体状态，不使用逻辑附件。

下降速度 60 mm/s，末端 25 mm 范围内 10 mm/s，起步加速 0.3 s；松爪前保持 0.5 s，夹爪在 0.3 s 内渐进打开，等待 4 s，侧向退出 60 mm，再观察 4 s。第 5 位必须先在层外下降，不能从上方贯穿层板。进入层间后的最终下降保持 XY 和姿态固定。

主入口默认启用 `--stable-placement`。`--no-stable-placement` 可显式复现旧放置段；兼容实验入口 `collect_physical_failure_isaacsim.py` 保持旧默认，需要显式传入 `--stable-placement`。`--execution-mode hybrid` 仍是历史混合回放模式，稳定放置控制器用于默认的 `physical` 采集。

历史参考轨迹可以继续用作抓取/运输参考，其原始文件、轨迹和 task hash 均保留。新放置策略另有 `profile_hash`，写入物理采集的 report 和 scene snapshot；实际执行目标与实际观测分别记录。新任务的五状态配置也随 task snapshot 冻结。

示例（在 DataPipe 目录执行）：

```powershell
& D:/Anaconda/envs/isaaclab/python.exe scripts/collect_isaacsim.py `
  --reference-run data/five_state_bidirectional_gui_20261009/0_to_2 `
  --output ../artifacts/placement_integration_20261013/example_0_to_2 `
  --no-gui --contact-velocity-iterations 4
```

验收标准：

1. 五状态放置坐标与搜索结果逐项相等，旧坐标在配置中以注释保留。
2. 根据倾斜的实际抓取关系换算 TCP，重建出的物体根位置等于配置松爪位置；原成功目标不变。
3. 主入口默认把稳定放置选项传给实际执行器；保存的 action 与实际执行的关节和夹爪目标一致。
4. 第 5 位先在层外下降、水平进入，最后仅下降 5 mm；松爪在下降之后，侧向退出在松爪之后。
5. 真实采集的观测、奖励时序、相机绑定和放置几何均通过独立审计。任务失败仍保存为失败数据，不能用采集数据审计通过冒充任务成功。

验证记录：相关自动检查 120 项通过。主入口真实采集 `0_to_2_01` 的 `task_succeeded=true`、`stable_placement.passed=true`，独立物理审计通过；1937 个观测、1936 个转移、483 张原生相机图像。退出后物体位置误差 1.446 mm、姿态误差 0.069°、角速度 0.0278 rad/s，连续稳定约 3.98 s。原参考文件校验值未变。非法碰撞及几何重叠的完整奖励证据覆盖仍沿用原限制，完整训练奖励有效性为 false。

实际采集结果位于工作区外层的 `artifacts/placement_integration_20261013/0_to_2_01`，验收汇总为该目录父级的 `acceptance.json`。本轮未逐条重跑其余完整搬运路线；五个配置坐标和第 5 位进入路径的控制顺序均已有自动检查，但第 5 位的新完整侧向进入路径尚未完成物理采集验证。
