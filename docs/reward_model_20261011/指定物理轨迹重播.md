# 指定物理轨迹重播

入口：`scripts/replay_physical_trajectory_isaacsim.py`。

此入口读取新增无携物实验的 `trajectory.npz`。同目录须保留匹配的
`scene_snapshot.json`、`report.json`、`trace.json`；仅移动 NPZ 不足以重建物体状态和真实动作。
原规划产物的重播入口仍为 `scripts/replay_isaacsim.py --run <原规划目录> --backend isaacsim`。

## 在 PowerShell 中运行

下列命令使用绝对路径，可在任意工作目录执行。默认打开 Isaac Sim 窗口，按 60 Hz
播放实测机械臂、两指及物体状态，最后停留 30 秒。

```powershell
& "D:\Anaconda\envs\isaaclab\python.exe" "D:\Project\S2R\DataPipeline\DataPipe\scripts\replay_physical_trajectory_isaacsim.py" --trajectory "D:\Project\S2R\DataPipeline\DataPipe\data\physical_failure_20261011\0_to_2_natural_08\trajectory.npz" --mode state --hold-s 30
```

把 `--trajectory` 改为 `0_to_2_open_after_grasp_02\trajectory.npz` 的完整路径即可重播受控掉落轨迹。

## 模式和输出

- `--mode state`：逐帧恢复实测关节、夹爪与物体状态，不推进物理仿真，展示已记录轨迹。
- `--mode action`：只在初始化时恢复状态，此后发送记录中实际执行的关节/夹爪目标，按原物理频率推进 PhysX。
  开爪注入的实际动作也会重播；不把实测关节响应误作控制目标。结果可能与原轨迹不同。
- `--save-images`：额外保存三视角 256×256 PNG，每 12 个轨迹帧采样一次。
- `--check-only`：仅校验轨迹、配套文件和 USD 资产，不启动仿真。
- `--headless`：无窗口；`--no-realtime`：按最快渲染速度执行全部帧。
- `--max-frames 12`：仅重播前 12 帧，用于启动检查；报告会标明未重播完整轨迹。
- `--output <新目录>`：指定输出目录。默认在工程 `data/physical_replays/<运行时间>` 新建目录。
  输出包含 `replay_report.json` 和 `replay_trace.json`，启用图片时还包含 `execution_visualization`。

程序拒绝覆盖既有输出目录或向输入轨迹目录写入，记录输入 SHA256 并在退出时确认原文件未变。
重播报告中的 `passed` 表示重播完成和状态读回检查通过，不是稳定放置成功标记；该脚本不重算奖励。
