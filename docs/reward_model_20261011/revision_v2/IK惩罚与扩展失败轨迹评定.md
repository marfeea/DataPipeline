# IK 惩罚与扩展失败轨迹评定

日期：2026-10-11。候选版本：`pick-place-candidate/2`。按用户本轮要求补充 IK 失败项；速度、加速度超限暂不增加事件罚分。独立离线实现完成，主采集接入仍待批复。v1 模型及两轮冻结结果保留。

## 1. v2 的确切修改

在 v1 的到达、抬升、位置/姿态、抓取/释放、时间、速度平方、重叠和原失败项基础上，增加：

\[
R_{\rm diag}=\sum_{t=0}^{N-2}r_t^{(v1)}-15\,\mathbf{1}[\text{本回合被明确的执行 IK 失败中止}].
\]

权重 15 是工程起点，与既有超时罚项等量；不是论文直接给定或训练优化得到的数值。成功释放前的到达/抬升/位置/姿态/已验证抓取累计正贡献最多 12，因此该事件可覆盖已有进展收益；一旦已成功或已有安全终止，不追加第二次终止罚分。

只对原报告明确的 `RuntimeError: Legacy IK failed in legacy_approach_pick/legacy_lift/legacy_place_approach`，且与报告执行阶段一致的 **回合中止** 计费。暂时一次求解失败但重试恢复、规划端点世界碰撞拒绝、未达到容差的超时、渲染/依赖错误，都不能冒充 IK 中止。

`scripts/pick_place_reward_candidate_v2.py` 复用 v1 的物理转移公式，新增 `abort_ik_failure(stage)`，一个实例只计一次；触发后候选评分实例结束。`scripts/evaluate_failed_pick_place_rewards_v2.py` 验证原证据，输出独立事件账本。

**时序契约：IK 异常在 `step_ik` 的物理推进之前发生。** 原 trace 没有失败尝试的新物理状态、动作或可靠事件时间，所以不能伪造下一帧，也不能宣称上一条已执行动作本身 IK 失败。v2 保留全部 N−1 条原转移奖励，另存 `controller_events.json` 的 −15。事件注明发生于最后已记录观测之后，`event_time_s=null`；总分是转移总分加事件总分。此前执行进展不回撤、不改写；CSV 是物理转移分，含事件的总分必须看 summary，不能只对 CSV 求和。

这区别于上轮超时的回溯标注：超时是在执行足够步数后明确报错，仍沿用最后一条已有转移上的 −15 标注。两种历史标注均不是已有效的在线训练数据。所有转移和事件 `reward_valid=false`。

**速度、加速度超限事件费用均为 0。** 原有 `−0.01∫Σdq²dt` 运动代价保留，与“超过阈值额外罚分”分别表达；现有产物速度/加速度门禁也保留。没有新增 ddq 项、没有放宽验收、没有抹掉拒收原因。

## 4. 惩罚是否对应失败原因

**明确 IK 中止已覆盖。** 原抬升前缀的 +3.622064 保留为既有动作进展，新增事件 −15 后总分 −11.377936。0→4 放置 IK 失败时物体距目标 236.295 mm，2→4 对应 215.644 mm；二者都未到释放阶段，不会得到成功奖，均扣一次 IK 事件。

**超时在多个执行阶段生效。** 4→0 局部抬升的未计 timeout 分量合计 +1.160103，−15 后为 −13.839897；2→4 接近未计 timeout 为 +0.717115，−15 后为 −14.282885；0→4 外侧下降未计 timeout 为 +0.001573，−15 后为 −14.998427。明确阶段 deadline 足以给这些不完成样本负总分，不需要新增通用失败项。适配器校验 timeout 异常阶段与末帧阶段一致，历史报告 `legacy_approach` 是已知的接近前标签别名。

**疑似空抓不是已证实的“抓住后掉落”。** 4→0 该记录：物体 reset→末帧净位移 6.142 mm；抬升/退出段内 TCP 位移 168.623 mm，物体仅 5.802 mm；末帧指关节接近闭合零位。报告确认“目标位移小于 100 mm”的拒收，但没有双指目标接触、持续抓持和随后丢失抓持的证据，不调用既有 `dropped` −10，也未新增 grasp_failed 罚项。

该疑似空抓的 −1.380723 来自到达 +1.826439、离线抬升代理 +2、时间 −0.2、速度平方 −0.007162、托盘几何重叠 −5。**负分主要不是空抓专门罚分。** 5 mm 的局部抬升归一化很容易因几毫米物体位姿变化饱和，而夹爪接近闭合也不能证明持物。若无 overlap −5，其余累计反而为 +3.619277。这进一步说明应增加物理抓取证据，不能依赖位移阈值或奖励正负自动分类。

本轮没有找到已具备“先确认抓持、再丢失”的完整证据链、可以可靠调用 dropped −10 的历史轨迹。没有把未随夹爪移动、计划携物、松爪后的正常下降、几何重叠或 IK 失败伪标成掉落。
