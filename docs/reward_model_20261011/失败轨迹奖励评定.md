## 4. 对期望行为与后续接入的含义

v1 仍鼓励靠近抓取点、取得足够的垂直净空、把物体送到目标、校正姿态、减少等待与过快运动；若有完整物理证据则鼓励可靠抓取和稳定松爪。F 说明明确 deadline 能抑制长时间失败尝试。A–C/E 则说明“进展收益为正”不足以保证满足动力学约束或最终完成。

本轮不改 v1。接入前应将这些病例加入验收集合，并分别保留执行 outcome、产物门禁 outcome、证据有效性与累计 reward，不能用 `return>0` 作为成功标签。建议另立 v2 评审：显式读取速度/加速度限值和超限事件，设计按时间/限值归一化的代价；定义有证据的 IK/规划拒绝与未完成 outcome，避免混用物理碰撞罚分；在统一起点和完整窗口的数据上验证成功/失败区分。新版终止与罚分的作用时刻需独立定义，规划前失败不能凭空造物理转移。以上仅为后续建议，未改公式、未自动接入主逻辑。
