# Pick-and-place 奖励建模调研与论文阅读卡片

检索/核对日期：2026-10-11。用途：当前 AUBO 采样瓶抓放的数据奖励增量提案。
本库没有 `doc/` 综述模板，按项目既有 `docs/` 布局保存。以下区分论文原文、作者代码、工程推断、待确认。
不宣称穷尽所有顶刊顶会；筛选标准是抓放奖励有可核查定义，且能映射当前数据。

## 批次总览

8 篇同行评审论文（2017—2023）及 1 项官方实现参考。
直接相关：HER、Meta-World、ManiSkill2、精确抓放、RLBench、CoRL 6-DoF 抓放、T-RO HSA；
IROS VPG 只支撑抓取事件奖励，不把它说成完整放置模型。
奖励按三类比较：目标稀疏判据、阶段门控塑形、由真实结果学习的奖励。
这批文献主要研究单臂，只有 ManiSkill2 总体 benchmark 还覆盖双臂；不能自动外推双臂闭链/内力。

## 1. Hindsight Experience Replay

- **基本信息**：Andrychowicz 等，NeurIPS 2017；OpenAI 团队；奖励相关章节 §3、§4.1、§4.4 已读。
  [会议论文](https://proceedings.neurips.cc/paper/2017/file/453fadbd8a1a3af50a9df4df899537b5-Paper.pdf)。本地 PDF 未保存。
- **研究对象/贡献**：Fetch 单臂、双指、MuJoCo，含 pick-and-place 与实机转移；HER 对失败轨迹重标可达目标。
- **问题/方法**：稀疏成功难探索；state 与 goal 输入 DDPG，按 `o0,a0,o1` 重算 reward。
- **奖励原文**：`r(s,a,g)=−I[f_g(s′)=0]`，`f_g(s)=I[‖p_o−g‖≤ε]`。目标是物体位置；
  原任务允许目标悬空，因此这套判据不要求释放。ε 不替本文工程阈值；论文评估 pick-place 用 7 cm。
- **动力学/实验**：策略不显式学习接触方程；仿真提供状态演化。比较 DDPG/HER、目标采样与塑形，指标为成功率。
- **限制/关联（推断）**：悬空到位与瓶子稳定放置不同；仅几何距离难识别“夹着不放”。适合综述 RL 目标条件与评估章，
  对多臂内力无直接证据。代码见论文项目引用，复现难度中。

## 2. Meta-World: A Benchmark and Evaluation for Multi-Task and Meta Reinforcement Learning

- **基本信息**：Yu 等，CoRL 2019，PMLR 卷于 2020 出版；Stanford/Berkeley 等；§4.2、附录 B 已核。
  [正式页面](https://proceedings.mlr.press/v100/yu20a.html)、[全文](https://proceedings.mlr.press/v100/yu20a/yu20a.pdf)。
- **对象/问题/贡献**：Sawyer 单臂双指、MuJoCo，多任务泛化；统一 50 任务状态/动作与奖励结构。
- **原文方法**：pick-place 的 `R=R_reach+R_grasp+R_place`，共享尺度。动力学由仿真，不是接触辨识模型。
- **版本核对**：[固定 v2.0.0 源码](https://raw.githubusercontent.com/Farama-Foundation/Metaworld/v2.0.0/metaworld/envs/mujoco/sawyer_xyz/v2/sawyer_pick_place_v2.py)
  `compute_reward` 行 163—185：令 C=caging/gripping、T=目标 long-tail tolerance，未到位时为
  `H(C,T)+I_near_and_lift(1+5T)`；`H(a,b)=ab/(a+b−ab)`。目标距离 `<0.05 m` 时覆盖为 10。
  `evaluate_state` 的 success 距离门槛却为 `≤0.07 m`，不能混淆 reward 覆盖与评估。
- **实验/限制/关联**：原文比较 multi/meta RL，以任务成功率评估。V2 是后续实现，不能宣称上述数值来自 2019 原文。
  [官方版本说明](https://metaworld.farama.org/benchmark/reward_functions/)确认 V1/V2 有区别。
  本项目借鉴阶段化，不直接复制大尺度旧奖励。综述 benchmark/奖励设计章，复现中、开源、主要仿真。

## 3. ManiSkill2: A Unified Benchmark for Generalizable Manipulation Skills

- **基本信息**：Gu、Xiang 等，ICLR 2023，UCSD/Tsinghua；[作者项目](https://maniskill2.github.io/)、
  [会议论文](https://openreview.net/pdf/a180ff20bf660bc9f8a2f007193ed71e83ba91f7.pdf)。会议页本次触发浏览器验证，摘要检索与固定代码已核。
- **对象/贡献/方法**：SAPIEN 动力学，多类刚/软体操作，总体覆盖单/双臂；本次只分析单臂 PickCube。
- **官方代码证据**：[ManiSkill v0.5.3 的 ManiSkill2 PickCube](https://raw.githubusercontent.com/mani-skill/ManiSkill/v0.5.3/mani_skill2/envs/pick_and_place/pick_cube.py)，
  `evaluate` 行 61—75、`compute_dense_reward` 行 77—98。
- **精确公式**：失败/进行中 `r=1−tanh(5d_tcp,obj)+I_grasp[1+1−tanh(5d_obj,goal)]`；
  success 时返回 5，normalized reward 除 5。success=`d_obj,goal≤0.025 m` 且非夹爪关节最大绝对速度 `≤0.2 rad/s`。
- **实验/动力学/限制**：benchmark 提供任务、示范和评估接口，接触由仿真；公式来自固定官方实现，未声称是论文逐字公式。
  PickCube 可把目标设在空中，不等价于释放并承托。项目采纳物体目标与静止验证，另外加入释放。
  综述 benchmark 章，高价值，复现中；具体版本真实实验细节待确认。

## 4. Self-Supervised Learning for Precise Pick-and-Place Without Object Model

- **基本信息**：Lars Berscheid、Pascal Meißner、Torsten Kröger；KIT；IEEE RA-L 5(3), 4828—4835，2020，
  DOI `10.1109/LRA.2020.3003865`。[全文](https://arxiv.org/pdf/2006.08373)、[项目/代码入口](https://pantor.github.io/learning-pick-and-place/)。
  本地 `data/reward_research_20261011/sources/precise_pick_place.pdf`；§III-C/D 精读，其他奖励相关粗读。
- **对象/问题/贡献**：Panda 单臂自制双指、RGBD/深度，真实平面抓放；无物体模型时从一个目标图像学精确放置。
- **奖励原文**：放置分数 `ξ(s′)=p(C=1|s′,s′_grasp,s′_place)∈[0,1]`，真实结果对为正样本、噪声对为负；
  ψ 为二值抓取成功的预测概率。NCE/BCE 是训练目标，ξ 才是解释为放置 reward 的输出，不把 loss 值直接加到 RL 奖励。
- **实验/建模**：FCNN grasp/place 和 merge embedding，未显式建模接触动力学；训练最多 25,000 次实际抓放。
  已训练物体放置约 2.7 mm/2.6°，未知物体约 5.9 mm/4.1°。
- **限制/关联（推断）**：平面原语不能直接覆盖当前三维约束路线；我们没有其训练分类器，不编造 ξ 的两路数值。
  采纳“结果与目标比较”原则，暂用可解释位姿。综述学习式奖励/精确操作章，实机复现难度高。

## 5. RLBench: The Robot Learning Benchmark & Learning Environment

- **基本信息**：Stephen James、Zicong Ma、David Rovick Arrojo、Andrew J. Davison；Imperial；IEEE RA-L 2020。
  [作者库](https://github.com/stepjam/RLBench)、[论文](https://arxiv.org/pdf/1909.12271)、
  [机构出版记录](https://spiral.imperial.ac.uk/entities/publication/05d81ed0-faec-441d-8d60-703bfba8cddb)。本地 `rlbench_paper.pdf`，API/奖励段已读。
- **对象/问题/贡献**：Panda 单臂、CoppeliaSim/PyRep；多任务视觉操作与规划器示范，标准化任务条件。
- **精确奖励**：论文说明仅完成时 +1；[当前作者 API](https://raw.githubusercontent.com/stepjam/RLBench/master/rlbench/task_environment.py)
  `step` 行 91—100 默认 `reward=float(success)`，失败/进行中 0；显式启用 shaped 时调用 task 自己的 reward。
- **动力学/实验/限制**：物理与条件来自仿真环境，非接触模型学习；指标是任务完成率。不能把每项 task 都假定有 dense reward，
  master 是本次访问版本，没把新接口特性归为 2020 原始版本。
- **当前关联（推断）**：独立维护成功与塑形，有利于数据评估一致性；多臂约束/内力不在本卡证据内。
  综述 benchmark/示范数据章，开源，仿真复现中；原论文实机定量待确认。

## 6. Learning 6-DoF Grasping and Pick-Place Using Attention Focus

- **基本信息**：Marcus Gualtieri、Robert Platt，Northeastern，CoRL 2018；
  [会议页面](https://proceedings.mlr.press/v87/gualtieri18a.html)、[全文 §5](https://proceedings.mlr.press/v87/gualtieri18a/gualtieri18a.pdf)。奖励段已读，本地 PDF 未保存。
- **对象/问题/贡献**：单臂 6-DoF 抓放；sense-move-effect MDP 与 HSE3S 缩小位姿搜索，仿真训练后实机转移。
- **原文奖励**：grasp/place 各 `[0,1]`；所有必需条件满足才非零，之后按部分信用条件比例给分。
  瓶子放置必需条件含有效抓取、竖直角度≤30°、位于杯垫上、间距≤4 cm、特定无碰撞条件；
  部分信用包含≤15°、间距≤2 cm 和无碰撞。
- **建模/实验**：OpenRAVE/3DNet、视觉 Q 学习、原语执行；没有学习显式接触动力学。评估 block/mug/bottle 抓放成功。
- **限制/关联（推断）**：门槛含任务几何先验；本工程 10°/20 mm 不是论文原门槛。
  支持“姿态不能从位置成功推断”的设计；综述 RL/任务约束章，高价值，开源链接见正式页，复现中。

## 7. Learning Manipulation Skills Via Hierarchical Spatial Attention

- **基本信息**：Gualtieri、Platt，Northeastern；IEEE T-RO 2020，DOI `10.1109/TRO.2020.2974093`。
  [作者出版页](https://www2.ccs.neu.edu/research/helpinghands/publication/marcus_hierarchical_spatial/)、
  [作者预印本 v3](https://arxiv.org/pdf/1904.09191)；§V-C/D 已读，本地 PDF 未保存。
- **对象/贡献/方法**：UR5、Robotiq 85、深度；HSA 扩展先前 CoRL 方法，以分层视觉 Q 减少搜索，含物理瓶/杯垫。
- **精确奖励（§V-C）**：抓未放瓶且抓点距瓶底>4 cm：+1；抓已放瓶：−1；正确放瓶：+1；其他：0。
  放置条件含竖直、CoM XY 在空杯垫边缘内至少 2 cm、瓶底距垫面±2 cm。
- **实验/结果**：30 个双瓶回合，60/59 次 grasp/place 尝试；成功率 .98/.90，整任务 .67。
  实机成功判据另要求撤爪后瓶子仍留在杯垫。
- **动力学/限制/关联（推断）**：原语与几何/antipodal 条件，非内力/摩擦辨识；支持结果撤销扣信用和松爪后核验。
  2 cm 是垫面与边缘相关条件，并非三维根位置欧氏阈值；本工程未复制。综述任务约束/评估章，高价值，复现中。

## 8. Learning Synergies between Pushing and Grasping with Self-Supervised Deep Reinforcement Learning

- **基本信息**：Zeng、Song 等；Princeton/Google/MIT；IROS 2018。
  [全文 §IV-D](https://arxiv.org/pdf/1803.09956)、[作者项目](https://vpg.cs.princeton.edu/)；奖励段已读，本地 PDF 未保存。
- **对象/问题/贡献**：UR5/RG2 单臂双指，RGBD，仿真和实机；以 FCN Q 联合学 push 与 grasp 的互助关系。
- **奖励原文**：成功抓取 +1，抓后两指间距判定；产生超过阈值的 heightmap 改变的 push +0.5；否则 0。
- **动力学/实验**：model-free、原语和仿真接触；比较 clutter 完成率、抓取率、动作效率；并有取消 push 奖励的消融。
- **限制/关联（推断）**：不含目标位姿放置判据；其 reward 不可替代本项目完整抓放模型。
  仅借鉴真实事件核验，避免闭爪指令即发成功奖。综述自监督抓取/长程信用背景，中优先级，开源，复现中。

## 9. robosuite 官方实现补充（不计为顶会/期刊论文）

[项目与正确引用](https://robosuite.ai/)列出框架为 arXiv `2009.12293`；
[固定 v1.4.1 PickPlace 代码](https://raw.githubusercontent.com/ARISE-Initiative/robosuite/v1.4.1/robosuite/environments/manipulation/pick_place.py)
`reward` 行 226—262、`staged_rewards` 行 263—347：
`r=n_placed+max(r_reach,r_grasp,r_lift,r_hover)`（shaping 开启），再乘 reward scale，四物体模式除 4。
reach=`0.1(1−tanh(10d))`，grasp=`0.35I_grasp`，lift 与 hover 的标度分别至 .5/.7。
这提示不应机械累加同一时刻所有静态阶段分数；本方案转为阶段进度差与一次事件。
其 MuJoCo 单臂 bin 放置机制不等价于当前瓶子精确姿态与托盘支撑，不直接套权重。

## Benchmark、方法和可引用证据积累

| 素材类型 | 可复制观点 | 原文位置 | 与双臂动力学关系 |
|---|---|---|---|
| Benchmark | Meta-World 给共享阶段结构；ManiSkill2 给物体目标/静止；RLBench 给任务条件 | 对应上方原文/源码位置 | 评估协议可借鉴，内力/闭链验证仍缺 |
| 方法 | HER 的目标重标与阶段门控 dense reward 是两种不同思路，不应混写为同一算法 | HER §3/4；Meta §4.2 | 可推广目标表示，不能证明多臂接触稳定 |
| 可引用证据 | 放置位置到位不自动代表松爪后稳定放置 | HSA §V-C4；Precise §III-C | 推断：多臂需额外验证释放协同与残余内力 |
| 研究空白 | 当前数据缺真实抓持/支撑、物体速度与松爪稳定窗口，reward 证据需扩展 | 本工程 trace/report，非论文结论 | 后续多臂还需同步双方 wrench、接触与约束状态 |

价值判断：可支撑综述“任务目标/成功条件”和“学习式操作奖励”材料；多数不是动力学辨识论文，
不作为双臂解析/学习动力学的核心代表。对当前工程，最有价值的是 HSA 的稳定放置核验、
Meta/ManiSkill 的阶段塑形，以及 Precise 的结果导向。
