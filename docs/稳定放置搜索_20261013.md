# 稳定放置搜索

持续目标：从“夹稳物体、完成高处 XOY 对准”的初态开始，找到保持 X/Y/姿态不变、沿世界 Z 下降后可开爪稳定放置的参数；重复验证并检查五个目标位。

## 首版范围与验收

- 新脚本 `scripts/search_stable_placement_isaacsim.py`，独立输出，不改原采集器、物理参数和目标门禁。复用生产 USD 场景、原 IK 及 PhysX。
- 初态取 `artifacts/physical_integration_20261013/0_to_2_natural_final/trace.json` 中最后一个真实抓持成立的高处运输帧。用其 TCP→物体关系反算候选 TCP 位姿，允许试验开始时初始化机械臂/物体状态；开始后禁止写机械臂或物体状态，无逻辑吸附。
- 每次先保持 0.75 s，最后至少 0.25 s 验证双指接触、无支撑接触、抓持相对位姿变化不超过 5 mm/5°，才能开始下降。
- 下降保持世界 XY 和完整姿态目标不变：默认高处净空 0.4 m，常规速度 0.06 m/s，最后 25 mm 降至 0.01 m/s，起步限速，停稳 0.5 s，0.3 s 逐步开爪。
- 使用 `RewardConfig` 当前默认值：物体位置误差 ≤ 0.02 m，姿态误差 ≤ 10°，线速度 ≤ 0.03 m/s，角速度 ≤ 10°/s，双指开度达到原门禁，有实际支撑接触。搜索额外要求物体已脱离双指接触。
- 开爪后观测 2 s，最后连续稳定至少 0.25 s。单独记录 `placement_passed`，不把撤爪结果混成放置结果。
- 再沿夹爪进入方向反向退出 60 mm，观测 2 s，最后连续稳定至少 0.5 s。总通过还要求下降/开爪的 TCP 最大 XY 跟踪误差 ≤ 3 mm，没有观测到非法大力接触或关节限位。
- 五个目标位各自测试，候选重复并施加毫米级位置与小角度扰动。最终交付精确高处/释放 TCP 位姿、相对目标偏移、动作参数、结果表、物理轨迹和可视证据。

## 实验记录

输出根目录：`artifacts/placement_search_20261013/`。

1. `smoke_01`：校准释放点在开爪后稳定约 2 s，最终上撤会重新碰到物体，导致约 31.6°倾斜。因此将撤爪作为独立阶段，并使用反向水平退出。纯 Z 下降与开爪保持不变。
2. `lateral_01`：先扫描释放 Z 偏移 0、+3、−3、+6、−6、+10、−10 mm。初始两点通过，后续结果见本目录 `summary.json`。

## 使用

在 `DataPipe` 目录运行：

```powershell
& D:/Anaconda/envs/isaaclab/python.exe scripts/search_stable_placement_isaacsim.py `
  --grasp-trace ../artifacts/physical_integration_20261013/0_to_2_natural_final/trace.json `
  --output ../artifacts/placement_search_20261013/new_run `
  --destinations 2 --max-trials 7 --headless
```

每次创建独立目录。`--resume` 仅在脚本、输入、配置和候选一致时继续。`--candidates` 可指定候选字段的 JSON 数组；`--capture` 保存真实三相机渲染。

## 证据边界

这是隔离放置实验，初始化高处夹持状态不证明整条抓取/运输路径成功。抓持稳定和支撑由真实接触张量验证。原系统的 PhysX 成对接触报告可能没有事件，因此输出明确标识 `collision_evidence_complete=false`，不能把缺少报告当作已验证全面无碰撞，也不能把本实验作为完整奖励证据。找到稳定点后仍需将其接入整条真实搬运路径验证。
