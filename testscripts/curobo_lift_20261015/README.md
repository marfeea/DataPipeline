# CuRobo 同起终点抬升对比

复用 Legacy IK 实验的源 0、候选 01、低速接近/闭爪、闭爪后 0.35 s 稳定。以本次实测抓取位姿起步，目标使用原实验 lift TCP 位姿。

先生成标准关节空间 MotionGen 轨迹，再生成保持末端姿态和 Y 坐标的 PoseCostMetric 轨迹。实测起点 X 比名义目标偏差约 6 mm，超过 CuRobo 的 5 mm 固定 X 初始验证容差，因此第二种不把 X 写成固定约束；独立记录两种轨迹相对于起终点直线的最大偏差，不把同起终点等同于完全相同的空间曲线。

补充 `line` 模式：仅在规划机器人字典中增加与 project_tcp 同原点的固定虚拟工具坐标系，使其目标系 Z 轴平行于实际起终点连线。在该坐标系中固定姿态及 X/Y 投影，允许 Z 推进；物理 TCP 的目标位置与姿态完全保持原值。独立验收实际直线偏差 ≤ 1 cm，避免将名义起点约 6 mm 偏差误当成非法固定 X 约束。

全部通过位置目标 + PhysX 时间步执行，不在抬升期间写入机器人关节状态或物体位姿，不使用速度前馈。命令 60 Hz、物理 120 Hz。保留执行器与物理接触限制；本次取消 Legacy IK 的 1 cm 相对实测位置目标距离限制，不将其冒充为 CuRobo 的速度限制。

先核对含实测附着物体的完整碰撞世界起终点。若起点落入已有 support_tray_11 代理碰撞，则保留完整检查结果，只在显式诊断试验中从规划碰撞世界移除该托盘代理，物理场景完全不变；其余模型碰撞继续检查。若仍不合法则停止，不扩大豁免。

第一轮单球包围物体导致 support_tray_12 额外代理冲突，停止于规划之前；离线逐托盘诊断定位到附着球。重试将物体 TCP 系 AABB 分成四个规则网格单元，枚举分配方式并选择单元包围球半径最小的一种，每个单元用其包围球保守覆盖整个 AABB 并验证顶点覆盖，不扩大障碍物豁免。离线核查减少保守性后其余世界/自碰撞起终点评分均为 0。初次单球半径与新四球参数均保留在报告。

验收：GUI 在 Default 桌面有可见 Isaac 窗口；三路原生图片含接近、闭爪、稳定、抬升、保持并逐帧关联；目标误差 ≤ 1 cm、姿态误差 ≤ 1°；物体抬升 ≥ 35 cm，TCP 相对漂移 ≤ 5 mm / 5°，保持 ≥ 0.5 s。分别报告规划时间/速度、物理执行时间/速度、跟踪超前量、几何直线偏差、完整碰撞诊断。失败保留证据。

速度与阶段时长的时间基准为记录帧数 / 60，即物理仿真时间；启动、规划、GUI 渲染会增加墙钟耗时，应与机器人在仿真中的移动速度区分。
