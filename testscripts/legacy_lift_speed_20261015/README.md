# Legacy IK 抬升速度实验

2026-10-15 追加对比：显式传入 `--lift-step-m 0.01 --lift-command-hz 60`，仅改变抬升/抬升保持的 TCP 命令，接近与闭爪不变。
软件关节增量上限沿用上一轮的 0.785 rad，底层 3.14 rad/s 执行限制仍有效；物理 120 Hz 时对比 2 个物理步和 1 个物理步的关节插值。
闭爪稳定 0.35 s、抬升后保持 0.5 s。验收复用下列携带与图片标准；新配置须每个记录帧都更新 IK（60 Hz），实测 TCP 到本次目标的欧氏位移 ≤ 0.01 m。
使用独立批次 `legacy_lift_1cm_60hz_20261015`，与历史最快稳定的 5 cm / 4 Hz 结果比较，名义目标供给量为 0.60 m/s，不作为实际速度承诺。

本轮只在实验目录取消抬升阶段写死的 2/5 cm/s、1 mm 参考步长及 2 cm 跟踪超前限制，改为每 0.25 s 从实测 TCP 向目标推进最多 5 cm。
接近/闭爪使用同一套现有低速策略，保证各次抬升起点可比较。主采集入口和主配置不修改。

固定场景为用户最近运行的 0→1 路线、候选 01；执行器速度、关节位置范围和原有物理接触仍有效。
依次测试每条抬升命令的关节增量上限 0.08、0.16、0.32、0.785 rad；后者等于 3.14 rad/s ÷ 4 Hz。
若相邻两档出现性能平台，报告在本次场景和限制下测得的最快稳定结果，不声称全工作空间的全局最快速度。

第一轮已测得 0.32/0.785 rad 相同的 11.51 cm/s 平台，且关节增量限幅不再触发。
第二轮固定 0.785 rad，在闭爪后保持实测 TCP 位姿 0.35 s，让手指稳定握持，再测试关节插值占一个命令周期的 100%、50%、25%、6.67%。
这只改变两次 IK 命令之间的关节目标推进方式；IK 命令仍每 0.25 s 更新，TCP 目标相对实测位置总增量仍 ≤ 5 cm。

验收标准：

- 非无头 GUI，检查 Default 桌面上的 Isaac 可见窗口，三路原生 RGB 图片覆盖初始、接近、闭爪、抬升和抬升后保持。
- 物理 120 Hz、记录 60 Hz；抬升 IK 更新间隔 15 个记录帧，即 4 Hz；每次 TCP 目标增量的欧氏长度 ≤ 0.05 m。
- 抬升到目标容差 1 cm，物体竖直升高至少 0.35 m；末端到达后保持 0.5 s。
- 物体相对 TCP 的平移漂移 ≤ 5 mm，旋转漂移 ≤ 5°，作为本轮稳定携带标准。
- 以 TCP 世界 Z 位移除以抬升全段时间比较平均抬升速度，同时报告 TCP 路径平均速度、稳态中位速度和峰值速度。
- 记录实际 PhysX 接触和托盘碰撞诊断。速度试验沿用 run003 诊断策略，托盘碰撞诊断不作为速度门禁；有碰撞诊断的结果不能视为正式无碰撞路线。

运行前 `python testscripts/legacy_lift_speed_20261015/run_sweep.py --prepare-only` 生成可审查的实验副本和清单。
实际运行使用独立输出批次；GUI 初始化一次，各次试验从相同复位关节姿态和源物体姿态开始。
